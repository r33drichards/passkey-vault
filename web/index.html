Login details

Import from Bitwarden

Choose an unencrypted Bitwarden JSON export. Login names, usernames, passwords, URLs, and notes are imported. Cards, identities, and secure notes are skipped. Folders, custom fields, attachments, password history, saved passkeys, URI match rules, and TOTP seeds are not imported.

Exports contain plaintext secrets. Keep the file private and remove it when finished. Import adds new entries; repeating an import creates duplicates.

Recover with SSH

Sign a one-time challenge locally. Never paste or upload your private key.

1. Download the challenge, then sign it in your terminal within 5 minutes. Replace the key path with your private key.

ssh-keygen -Y sign -f ~/.ssh/id_ed25519 -n passkey-vault challenge.txt
